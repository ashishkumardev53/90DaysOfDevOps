Task 1: Basics
Shebang
Tells the system which shell interpreter to use.

#!/bin/bash
Without this, the script may run using the wrong shell.

Running a Script
Make executable:

chmod +x script.sh
Run directly:

./script.sh
Run using bash:

bash script.sh
Comments
Single-line comment:

# This is a comment
Inline comment:

echo "Hello" # inline comment
Used for documentation and readability.

Variables
Declare:

NAME="DevOps"
Use:

echo $NAME
Quoting:

"$NAME"   # expands variable (recommended)
'$NAME'   # literal text
Reading User Input
read username
echo "Hello $username"
With prompt:

read -p "Enter your name: " username
Command-Line Arguments
$0  # script name
$1  # first argument
$2  # second argument
$#  # total arguments
$@  # all arguments
$?  # last command exit status
Example:

echo "First arg: $1"
echo "Total args: $#"
Task 2: Operators and Conditionals
String Comparisons
[ "$a" = "$b" ]   # equal
[ "$a" != "$b" ]  # not equal
[ -z "$a" ]       # string is empty
[ -n "$a" ]       # string is not empty
Example:

if [ "$name" = "admin" ]; then
    echo "Welcome admin"
fi
Integer Comparisons
[ $a -eq $b ]  # equal
[ $a -ne $b ]  # not equal
[ $a -lt $b ]  # less than
[ $a -gt $b ]  # greater than
[ $a -le $b ]  # less or equal
[ $a -ge $b ]  # greater or equal
File Test Operators
-f file   # regular file
-d dir    # directory
-e path   # exists
-r file   # readable
-w file   # writable
-x file   # executable
-s file   # not empty
if / elif / else Syntax
if [ condition ]; then
    command
elif [ condition ]; then
    command
else
    command
fi
Logical Operators
cmd1 && cmd2   # run cmd2 if cmd1 succeeds
cmd1 || cmd2   # run cmd2 if cmd1 fails
! condition    # NOT
Case Statement
case $choice in
    start)
        echo "Starting"
        ;;
    stop)
        echo "Stopping"
        ;;
    *)
        echo "Unknown option"
        ;;
esac
Task 3: Loops
For Loop (List Based)
for i in 1 2 3; do
    echo "$i"
done
For Loop (C Style)
for ((i=1; i<=5; i++)); do
    echo "$i"
done
While Loop
Runs while condition is true.

count=1

while [ $count -le 3 ]; do
    echo "$count"
    ((count++))
done
Until Loop
Runs until condition becomes true.

num=1

until [ $num -gt 3 ]; do
    echo "$num"
    ((num++))
done
Loop Control
break — exit loop

for i in 1 2 3 4; do
    [ $i -eq 3 ] && break
    echo "$i"
done
continue — skip iteration

for i in 1 2 3; do
    [ $i -eq 2 ] && continue
    echo "$i"
done
Loop Over Files
for file in *.log; do
    echo "$file"
done
Loop Over Command Output
cat file.txt | while read line; do
    echo "$line"
done
Or safer:

while read line; do
    echo "$line"
done < file.txt
Task 4: Functions
Defining a Function
greet() {
    echo "Hello DevOps"
}
Calling a Function
greet
Functions run just by writing their name.

Passing Arguments to Functions
Inside functions:

$1 = first argument
$2 = second argument
welcome() {
    echo "Welcome $1"
}

welcome Dikshith
Output:

Welcome Dikshith
Return Values
Bash functions don't return strings — only numbers (0–255).

Using return (status code):

check() {
    return 0
}

check
echo $?
Using echo to send data:

add() {
    echo $(($1 + $2))
}

result=$(add 5 3)
echo "$result"
Local Variables
Without local, variables leak outside function.

demo() {
    local x=10
    echo "$x"
}

demo
x exists ONLY inside function.

Example Real Function
disk_usage() {
    echo "Top Disk Usage:"
    du -sh * | sort -hr | head -5
}

disk_usage
Functions help organize scripts, avoid repetition, and make code readable.

Task 5: Text Processing Commands
These commands help you SEARCH, FILTER, MODIFY, and ANALYZE text/log files.

GREP — Search Text
Search for pattern:

grep "error" logfile.txt
Case-insensitive:

grep -i "error" logfile.txt
Show line numbers:

grep -n "error" logfile.txt
Count matches:

grep -c "error" logfile.txt
Invert match (NOT):

grep -v "info" logfile.txt
Recursive:

grep -r "error" /var/log
Extended regex:

grep -E "error|failed" logfile.txt
AWK — Column Processing
Print first column:

awk '{print $1}' file.txt
Custom delimiter:

awk -F: '{print $1}' /etc/passwd
Pattern match:

awk '/error/ {print $0}' logfile.txt
BEGIN / END:

awk 'BEGIN{print "Start"} {print $1} END{print "End"}' file.txt
SED — Stream Editor
Replace text:

sed 's/old/new/' file.txt
Global replace:

sed 's/old/new/g' file.txt
In-place edit:

sed -i 's/foo/bar/g' config.txt
Delete lines:

sed '/error/d' logfile.txt
CUT — Extract Columns
By delimiter:

cut -d: -f1 /etc/passwd
Character range:

cut -c1-5 file.txt
SORT
Alphabetical:

sort file.txt
Numerical:

sort -n numbers.txt
Reverse:

sort -r file.txt
Unique:

sort file.txt | uniq
UNIQ
Remove duplicates:

uniq file.txt
Count duplicates:

sort file.txt | uniq -c
TR — Translate/Delete Characters
Lower → Upper:

tr a-z A-Z
Delete spaces:

tr -d ' '
WC — Count
Lines:

wc -l file.txt
Words:

wc -w file.txt
Characters:

wc -c file.txt
HEAD / TAIL
First 10 lines:

head file.txt
Last 10 lines:

tail file.txt
Follow logs live:

tail -f logfile.txt
Task 6: Useful Patterns and One-Liners
Find and Delete Files Older Than N Days
Delete files older than 7 days:

find /path -type f -mtime +7 -delete
Dry run (see first):

find /path -type f -mtime +7
Count Lines in All .log Files
wc -l *.log
Total lines across all logs:

cat *.log | wc -l
Replace a String Across Multiple Files
Replace foo with bar:

sed -i 's/foo/bar/g' *.txt
Recursive:

sed -i 's/foo/bar/g' $(grep -rl foo .)
Check if a Service is Running
Systemd:

systemctl is-active nginx
Old school:

ps aux | grep nginx
Disk Usage Above Threshold
df -h | awk '$5 > "80%" {print}'
Shows partitions above 80%.

Parse CSV from Command Line
Print first column:

cut -d, -f1 file.csv
Tail Logs and Filter Errors in Real Time
tail -f app.log | grep -i error
Find Biggest Files
du -ah / | sort -hr | head -10
Count ERRORs in Logs
grep -ci error logfile.txt
Check Open Ports
ss -tuln
Task 7: Error Handling and Debugging
This section teaches you how to make scripts SAFE, predictable, and debuggable.

Production scripts MUST fail loudly and early.

Exit Codes
Every Linux command returns an exit code.

0 → success
non-zero → failure
Check last command status:

echo $?
Manually exit:

exit 0   # success
exit 1   # failure
Example:

cp file1 file2 || exit 1
set -e (Exit on Error)
Script stops immediately when any command fails.

set -e
Example:

set -e
ls goodfile
ls badfile   # script stops here
echo "Never runs"
Why useful: Prevents silent failures.

set -u (Undefined Variables)
Script crashes if you use undefined variables.

set -u
Example:

set -u
echo $NOT_DEFINED   # crashes
Why useful: Avoids typo bugs and empty variables.

set -o pipefail (Pipeline Safety)
By default pipelines hide failures.

false | true
echo $?   # returns 0 (BAD)
Fix:

set -o pipefail
false | true
echo $?   # returns 1 (GOOD)
Now ANY failure inside pipe breaks script.

Full Strict Mode (Always Use in Real Scripts)
set -euo pipefail
This enables:

✔ stop on error
✔ stop on unset variables
✔ detect pipe failures
This is professional-grade scripting.

set -x (Debug Mode)
Prints every command before execution.

set -x
Turn off:

set +x
Example:

set -x
echo "hello"
ls
Used when debugging broken scripts.

Trap (Cleanup on Exit)
Run code when script exits or crashes.

Example:

cleanup() {
    echo "Cleaning up temp files"
}

trap cleanup EXIT
Now cleanup runs EVEN if script fails.

Used for:

✔ deleting temp files
✔ closing resources
✔ logging exits
Real Example
#!/bin/bash
set -euo pipefail

cleanup() {
    echo "Script finished"
}

trap cleanup EXIT

FILE="demo.txt"

cat "$FILE"
If demo.txt missing → script exits safely.

Summary
set -e → stop on errors
set -u → stop on undefined vars
set -o pipefail → detect pipeline failures
set -x → debug mode
trap → cleanup on exit
