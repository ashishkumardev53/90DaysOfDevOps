Day 14 – Core Networking + Troubleshooting Basics

Quick Concepts

OSI vs TCP/IP (in my own words)

OSI has 7 layers (Physical, Data Link, Network, Transport, Session, Presentation, Application). It’s mainly a learning and debugging model.

TCP/IP has 4 layers (Link, Internet, Transport, Application). This is what actually runs on real systems and the internet.

OSI helps understand where a problem lives. TCP/IP explains how data actually flows.

Where things sit in the stack

IP → Internet layer (TCP/IP) / Network layer (OSI)

TCP/UDP → Transport layer

DNS → Application layer

HTTP/HTTPS → Application layer

Real example: curl https://google.com = Application (HTTP) over Transport (TCP) over Internet (IP)

Hands-on Checklist

Target used: google.com

Used hostname -I

Observation: Shows my private IP address assigned to the machine.

Used ping google.com

Observation: Host reachable with low latency and no packet loss.

Used traceroute google.com

Observation: Traffic passes through multiple ISP hops; some hops timed out (normal due to ICMP blocking).

Used ss -tulpn

Observation: SSH service listening on port 22.

Used dig google.com

Observation: Domain resolved to multiple IP addresses (load balancing).

Used curl -I https://google.com

Observation: Received HTTP response (301/200), confirming web server availability.

Used netstat -an | head

Observation: Mix of LISTEN and ESTABLISHED connections.

Mini Task – Port Probe & Interpret

Listening port identified: SSH on port 22

Tested locally using nc on port 22.

Result: Port reachable.

If not reachable, next checks would be:

 Service status (systemctl status ssh)

 Firewall rules (ufw or iptables)
Reflection

Fastest signal when something breaks:

ping for basic connectivity

curl -I for application availability

If DNS fails:

Inspect Application layer first.

If HTTP 500 appears:

Start at Application layer and check logs.

Two follow-up checks in a real incident:

Verify service status and logs

 (systemctl and journalctl)
Check firewall and security group rules
